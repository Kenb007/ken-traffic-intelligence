# HK Traffic Intelligence

一個實時畫面，給你要決定怎樣過香港海港的那一分鐘。

![三條過海隧道、著色的道路、快拍，和當刻的警告，在同一個畫面](docs/board.png)

有人要到海港的另一邊。時間並不寬裕，開車的人問走哪一條隧道。你知道三個名字。那一分鐘你需要的是數字。運輸署公布了分鐘。HKeMobility 公布了道路、快拍和工程。天文台公布了會改變同一個決定的警告。如果問題在更北的地方，入境事務處公布了大堂的情況。這些本來各在自己的網頁。這個畫面讀那些公開檔案，把決定放在同一個螢幕上。

## 畫面上有什麼

**三條過海隧道，帶着分鐘。** 紅磡海底隧道、東區海底隧道、西區海底隧道在最上方。數字的顏色告訴你這次延誤是平常的，還是已經變了質。如果有一宗尚未結束的交通意外，它就在同一列，因為進路上一宗事故，是你在選定隧道之前應該聽到的事。最右邊是整個策略性路網的車速，讓你分辨是這一條隧道慢，還是整個早上都慢。你點一下正在考慮的那一條，地圖就移到產生該數字的道路。

**道路，用署方自己的顏色。** 暢順，是路還在走。緩慢，是它已經陷進一種延誤。擠塞，是它不再像一條路，而像一個你坐着的地方。顏色就是運輸署已經在用的那個詞。

**快拍，讓你看。** 海港一帶的公共快拍在你尚未放大時就留在地圖上，隧道口的快拍也是，因為人在決定要不要駛入的時候，想看的就是那些畫面。你點一下鏡頭，靜止的畫面就載入。

**八個陸路管制站。** 入境事務處說出每個大堂的情況，居民和訪客，入境和出境。旁邊的車輛，是通往口岸的策略性道路上的實時車速。這是公開車速檔案能够老實說出的部分。羅湖告訴你大堂。它是旅客過關的地方。公開檔案沒有私家車的輪候，畫面就把那裏留空。

**天氣，在同一列。** 生效中的天文台警告全部列出。嚴重的，放在你會看見的地方。天色安靜的時候，你仍看得到天文台的氣溫，以及過去一小時有沒有下雨。

**想看清單的時候，有一張清單。** 右下方的情報卡已經把值得先讀的事項排好。你可以把它收起。它變成底部移動的一行，讓你看着城市的時候，緊急的事項仍在眼前。沿底部可以換脚下的地面：衛星、街道，或者立起來的三維樓宇。車速、快拍、工程、隧道、意外、管制站，都可以各自打開或關掉。

螢幕上的文字，是香港通告所用的書面中文。畫面以繁體中文開啟。你要英文，開關在時鐘旁邊。

## 自己跑起來

你需要 Node.js。在這個資料夾：

```bash
npm install
npm run dev
```

然後開啟 [http://127.0.0.1:4317](http://127.0.0.1:4317)。

如果你是在改這個畫面，加上 `?feed=down`，可以看到車速檔案失敗時的樣子。加上 `?map=down`，地圖不在的時候，上方那一列仍在。數字自己站得住。

## 數字從哪裏來

這些都不是一套私人系統量出來的。各部門早已公布，分成不同的檔案，給不同的讀者。這個畫面做的，是讀那些檔案，把它們畫成同一個城市。

道路是運輸署的策略性中心線。檔案用香港 1980 坐標。把那些數字直接畫在現代地圖上，每條路都會偏到真實街道的左上方一點。地政總署公布了全港的改正：經度加 8.8 角秒，緯度減 5.5 角秒。改完，線就落在路上。線的顏色是署方自己的飽和等級。某一小段沒有等級的時候，畫面退回一個簡單的讀法：低於 30 km/h、30 至 50、以及 50 或更快。衛星圖下的山，是公開的 Terrarium 地形，抹平過，免得一塊只有幾米寬的小塊把雷達的小跳動畫成懸崖。如果那層地形沒有送到，地圖仍俯在衛星圖上，上方那一列也還在。

## 這是怎樣做成的

我用餘暇的二十四小時做成這件事。我想把這句話說清楚，因為「二十四小時」很容易聽成一場衝刺，一扇鎖上的門，一個人什麼都不做。那是一段一段來的餘暇。我在做的時候，只把一部分注意力放在上面。我會回來，看着海港，發現一條路畫錯了位置，然後去做別的事，再回來。

Grok 是另一雙手。我會說我想看到什麼，然後我們去查公開的資料裏究竟有沒有。那一天有很多時間是在這種爭論裏。過海時間，是我承認自己一再想要它之後，就變得明顯。隧道口的快拍比較久，因為它們在公開清單裏，在地圖上卻很容易被漏掉。管制站是同一個問題問在邊境：同一個決定，大堂裏是旅客，路上是駛向口岸的車。天氣留了下來，因為我要警告先出現在人面前，然後才是隧道的選擇。

我開始的是一幅海港的畫面。那是我不能從單一政府網頁得到的決定。其餘的東西後來都來了，因為每一件新的，都是在用另一種方式問它。一段餘暇，只有一部分注意力，加上 Grok，足以把它們放在同一個螢幕上。數據一直都是公開的。它需要的是有人願意坐下來對着它。
