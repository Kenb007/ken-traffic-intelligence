# HK Traffic Intelligence

香港的智慧城市儀表板，用城市已經公布的開放數據 API 建成。

![三條過海隧道、著色的道路、快拍，和當刻的警告，在同一個畫面](docs/board.png)

香港已經在公開地量度自己。運輸署公布過海隧道、策略性道路、快拍、工程和交通意外。入境事務處公布八個陸路管制站。天文台公布警告和天氣。每一項都是一個開放數據 API，也都是為自己的網頁而做的。這個儀表板讀那些 API，把它們畫成同一個城市，讓這個地方的實時狀態可以放在一起看：過海隧道怎樣在走，道路塗上什麼顏色，快拍看見什麼，邊境大堂怎樣，天氣又蓋在這一切上面。

## 畫面上有什麼

**實時狀態，橫在上方。** 紅磡海底隧道、東區海底隧道、西區海底隧道各自帶着分鐘，數字的顏色說出這次延誤是平常的，還是已經變了質。如果有一宗尚未結束的交通意外，它就在同一列。最右邊是整個策略性路網的車速，讓一條慢的隧道可以對着整個早上都慢的城市來讀。點一下某條隧道，地圖就移到產生該數字的進路。

**道路，用署方自己的顏色。** 暢順，是路還在走。緩慢，是它已經陷進一種延誤。擠塞，是它不再像一條路，而像一個城市坐着的地方。顏色就是運輸署已經在用的那個詞。

**快拍，讓城市可以被看見。** 海港一帶的公共快拍在你尚未放大時就留在地圖上，隧道口的快拍也是。點一下鏡頭，靜止的畫面就載入。數字說檔案量到什麼。畫面說那條路看起來怎樣。

**八個陸路管制站。** 入境事務處公布每個大堂的情況，居民和訪客，入境和出境。旁邊的車輛，是通往口岸的策略性道路上的實時車速，這是公開車速 API 能够說出的部分。羅湖報告大堂。它是旅客過關的地方。公開檔案沒有私家車的輪候，儀表板就把那裏留空。

**天氣，在同一列。** 生效中的天文台警告全部列出。嚴重的，放在會被看見的地方。天色安靜的時候，儀表板仍顯示天文台的氣溫，以及過去一小時有沒有下雨。

**一份已排好的清單，說這些 API 正在說什麼。** 右下方的情報卡已經把值得先讀的事項排好。你可以把它收起。它變成底部移動的一行，讓你看着城市的時候，緊急的事項仍在眼前。沿底部可以換脚下的地面：衛星、街道，或者立起來的三維樓宇。車速、快拍、工程、隧道、意外、管制站，都可以各自打開或關掉。

螢幕上的文字，是香港通告所用的書面中文。畫面以繁體中文開啟。你要英文，開關在時鐘旁邊。

## 自己跑起來

你需要 Node.js。在這個資料夾：

```bash
npm install
npm run dev
```

然後開啟 [http://127.0.0.1:4317](http://127.0.0.1:4317)。

如果你是在改這個儀表板，加上 `?feed=down`，可以看到車速 API 失敗時的樣子。加上 `?map=down`，地圖不在的時候，上方那一列仍在。數字自己站得住。

## 數字從哪裏來

畫面上每一個數字，都來自香港早已公布的開放數據 API。各部門把它們分成不同的接口，給不同的讀者。這個儀表板做的，是讀那些接口，把它們畫成同一個城市。

道路是運輸署的策略性中心線。檔案用香港 1980 坐標。把那些數字直接畫在現代地圖上，每條路都會偏到真實街道的左上方一點。地政總署公布了全港的改正：經度加 8.8 角秒，緯度減 5.5 角秒。改完，線就落在路上。線的顏色是署方自己的飽和等級。某一小段沒有等級的時候，儀表板退回一個簡單的讀法：低於 30 km/h、30 至 50、以及 50 或更快。衛星圖下的山，是公開的 Terrarium 地形，抹平過，免得一塊只有幾米寬的小塊把雷達的小跳動畫成懸崖。如果那層地形沒有送到，地圖仍俯在衛星圖上，上方那一列也還在。

## 這是怎樣做成的

我用餘暇的二十四小時做成這件事。我想把這句話說清楚，因為「二十四小時」很容易聽成一場衝刺，一扇鎖上的門，一個人什麼都不做。那是一段一段來的餘暇。我在做的時候，只把一部分注意力放在上面。我會回來，看着城市，發現一條路畫錯了位置，然後去做別的事，再回來。

我想要的是一個智慧城市儀表板：一個螢幕，讀香港已經在跑的那些開放數據 API。Grok 是另一雙手。我會說出想放上畫面的城市某一部分，然後我們去查公開的 API 裏究竟有沒有。那一天有很多時間是在這種爭論裏。過海的分鐘在行車時間的接口裏。隧道口的快拍在公開清單裏，畫上去之後卻很容易被漏掉。管制站是另一個部門的 API，一邊是大堂，一邊是通往口岸那條路的車速。天氣是天文台的 API，因為警告是城市狀態的一部分，應該在同一塊板上。

跟地圖爭得最久的是中心線。運輸署用香港 1980 坐標存放那些道路，現代地圖會把它們畫得偏離街道一點，直到用上地政總署的改正。改完，線就落在路上，署方自己的顏色才可以坐在上面。

我從那些開放接口開始，也從想把它們看成同一個城市開始。一段餘暇，只有一部分注意力，加上 Grok，足以把它們放在同一個螢幕上。API 一直都是公開的。它們需要的是一個儀表板。
